Rooted in Oahu was created to encourage cultural understanding and respectful exploration of the island.

The following references acknowledge educational resources and photography featured throughout this website.

Cultural & Educational Resources

The following organizations provide educational information about Hawaiian history, cultural traditions, and the natural environment of Oahu.

  • University of Hawaiʻi. Educational resources about Hawaiian culture, history, and the environment. University of Hawaiʻi Website
  • Bernice Pauahi Bishop Museum. Resources about Hawaiian history, traditions, cultural heritage, and natural history. Bishop Museum Website
  • Waimea Valley. Information about Waimea Valley, its cultural significance, native plants, and natural environment. Waimea Valley Website

Website Development

Rooted in Oahu was developed as a student project for WDD 131: Dynamic Web Fundamentals.

The website uses HTML, CSS, and JavaScript to create a responsive and interactive experience. Features include category filtering, saved favorites, a visitor interest form, and browser localStorage.

The purpose of this project is to encourage visitors to learn about Oahu beyond its tourist attractions by highlighting the island's culture, traditions, people, and connection to the land.
